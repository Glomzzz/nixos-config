# Waybar ownership

- `../waybar.nix`: Home Manager entrypoint and systemd integration.
- `settings.nix`: module layout, behavior, and actions, with Nix-resolved paths.
- `style.css`: GTK3 stylesheet; selector order is preserved from the original.
- `power-menu.xml`: GtkBuilder session/profile popup.
- `helpers.nix`: packages shell helpers with explicit runtime dependencies.
- `scripts/*.sh`: profile switching, idle inhibition, weather, and network
  speed/connection information.
- `tests.py`: offline JSON, failure-path, padding, XML/action, and CSS-order tests.

No JavaScript runtime is needed: Waybar consumes JSON settings, GTK CSS, XML menus,
and executable helpers. The Nix settings stay typed/generated by Home Manager.

Run the tests and build/shellcheck every helper:

```bash
nix build --no-link .#checks.x86_64-linux.waybar
```

## Audio controls

- Click the volume indicator to open pwvucontrol's native PipeWire GUI for
  per-application volume, output routing, and device profiles.
- The mixer opens floating in Niri. The old wiremix package, terminal launcher,
  and terminal window rule are removed.
- qpwgraph and EasyEffects remain available for patching and audio effects.

## Network controls

- Click the network-speed readout to open the GTK NetworkManager connection editor.
- Use nm-applet's network icon in the system tray for available Wi-Fi networks,
  connecting/disconnecting, VPN controls, and Wi-Fi password prompts.
- `../network.nix` owns the session service and enables the StatusNotifierItem
  protocol (`nm-applet --indicator`) required by Waybar's native Wayland tray.
- NetworkManager and saved connections are unchanged; the old nmtui launcher,
  palette, and terminal window rule have been removed.

## Bluetooth controls

- Click the Bluetooth indicator to open Blueman's device manager for discovery,
  pairing, connecting/disconnecting, and device settings. Its window floats in Niri.
- The existing Waybar connection count, device list, and battery tooltip are kept.
- `../bluetooth.nix` owns Blueman's session applet and pairing agent. Its tray
  icon and dependent connection-display plugin are disabled to avoid a second
  Bluetooth indicator; the package's XDG autostart entry is masked so only the
  session service starts the applet.
- NixOS enables `services.blueman` for its system D-Bus/polkit integration.
  Overskride is removed; BlueZ and existing pairings are unchanged.

Runtime layout and hardware behavior still require a desktop session to validate.
